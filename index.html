Mathematical Specifications

1. Arc-Length Parameterization Lookup Table (LUT)

Bézier splines parameterized by naive t ∈ [0, 1] accelerate on flat sections and decelerate in tight bends because the first derivative magnitude ‖B′(t)‖ varies along the curve.

To achieve uniform velocity traversal at a given musical tempo (v = BPM × (80 px / 60 s)), we construct a monotonic cumulative arc-length table S[m] using composite Simpson's 1/3 quadrature:

Δs ≈ (Δt / 6) × (‖B′(t0)‖ + 4‖B′(tmid)‖ + ‖B′(t1)‖)

Target distance s* = (v × Δt) mod L is inverted using binary search, linear parameter interpolation, and a Newton-Raphson refinement step:

trefined = t* − [sk(t*) − s*] / ‖B′k(t*)‖

2. Coordinate-to-Pitch Scale Quantizer & Tone Fluctuation

Standard graphics places (0, 0) top-left, while musical frequency increases upwards. Normalized vertical height u = clamp(1 − y / H, 0, 1) maps onto a 3-band piecewise logarithmic frequency scale spanning 110 Hz to 8000 Hz (allocated 22% / 70% / 8% of vertical height to give generous resolution to the melodic midrange):

0 ≤ u ≤ 0.22 (22% Bass):        f(u) = 110 × (300 / 110)u / 0.22         (110 – 300 Hz)
0.22 < u ≤ 0.92 (70% Midrange): f(u) = 300 × (2500 / 300)(u − 0.22) / 0.70  (300 – 2500 Hz)
0.92 < u ≤ 1.00 (8% Air):       f(u) = 2500 × (8000 / 2500)(u − 0.92) / 0.08 (2500 – 8000 Hz)

The resulting pitch maps to continuous scale degree dcont across the active modal scale and root, with optional per-line tone fluctuation for organic analog drift:

  • Solid Strokes: Glide with smooth, natural microtonal portamento, with tone fluctuation adding organic wandering drift.
  • Dotted / Roll Strokes: Quantized to discrete scale intervals or rapid rhythmic roll/ratchet bursts.

3. Horizontal Axis Spatial Panning & Timbral Color

The continuous horizontal position x ∈ [0, W] determines stereo spatial placement and high-frequency acoustic sheen:

pan = clamp(2 × (x / W) − 1, −1, 1),   cutoff = baseCutoff × (0.75 + 0.6 × (x / W))

Drawing from left to right physically glides sound through the stereo field from the left channel to the right channel, providing 3D acoustic perspective.
